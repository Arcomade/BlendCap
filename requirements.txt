# Model assets are NOT included in this repository and are not pip-installable.
# Place them under checkpoints/ at the paths below — the capture scripts read
# these exact locations (see save_mhr_data.py / save_face_data.py):
#
#   sam-3d-body-dinov3/          SAM 3D Body — GATED by Meta. Accept the license at
#                                https://huggingface.co/facebook/sam-3d-body-dinov3
#                                with your own account and download it. The pipeline
#                                expects model.ckpt AND assets/mhr_model.pt
#                                (+ model_config.yaml). REQUIRED.
#   yolo/yolo11m-pose.pt         Ultralytics YOLO11m-pose (AGPL-3.0), public:
#                                https://github.com/ultralytics/assets/releases
#                                REQUIRED (the default NVIDIA / PyTorch path uses it).
#   moge-2-vits-normal/model.pt  MoGe-2 focal-length model, public
#                                (HF Ruicheng/moge-2-vits-normal). Recommended:
#                                without it body capture still runs, but camera /
#                                focal estimation is less accurate.
#   mediapipe/*.task, *.tflite   MediaPipe face/pose models, public. Downloaded
#                                automatically from Google's CDN on the first FACE
#                                capture if absent (needed for face capture only).
#   onnx/*.onnx                  OPTIONAL — only the non-NVIDIA / ONNX Runtime path
#                                reads these; the default NVIDIA / PyTorch path never
#                                does. Public mirror:
#                                https://huggingface.co/Blendcap/blendcap-onnx-exports
#
# A clean machine also needs system tools the supported installer bootstraps for
# you but a manual build does not:
#   - git: required to install the `moge @ git+...` dependency above.
#   - Windows only: the Microsoft Visual C++ Redistributable (2015-2022, x64), or
#     torch / onnxruntime fail to import with "WinError 126".
